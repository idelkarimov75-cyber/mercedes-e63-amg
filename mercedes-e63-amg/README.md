# Mercedes-AMG E63 S 4MATIC+ - Информационный сайт

Интерактивный веб-сайт с полной информацией о Mercedes-AMG E63 S и 3D моделью автомобиля.

## Возможности

- 🚗 Интерактивная 3D модель автомобиля (Three.js)
- 📊 Полные технические характеристики
- 🎨 Изменение цвета модели
- 🔄 Вращение и управление камерой мышью
- 📱 Адаптивный дизайн

## Запуск

### Способ 1: Node.js сервер
```bash
node server.js
```

### Способ 2: npm
```bash
npm start
```

Затем откройте браузер и перейдите по адресу: **http://localhost:8080**

## Технологии

- HTML5
- CSS3 (Grid, Flexbox, анимации)
- JavaScript (ES6+)
- Three.js (3D графика)

## Управление 3D моделью

- **Мышь**: Перетаскивайте для вращения модели
- **Вращение**: Автоматическое вращение
- **Изменить цвет**: Циклическая смена цветов (чёрный, белый, золотой, красный, синий)
- **Сброс**: Возврат к начальному положению

## Характеристики Mercedes-AMG E63 S

- Двигатель: V8 4.0L Biturbo
- Мощность: 612 л.с.
- Крутящий момент: 850 Нм
- 0-100 км/ч: 3.4 секунды
- Максимальная скорость: 300 км/ч
- Привод: 4MATIC+ (полный)
